# BBE E-Learning System — QA Documentation

## Mục đích

Bộ tài liệu QA/Test Plan dạng Markdown, được chuyển từ test plan Python được cung cấp.

## Cấu trúc

- `01-test-plan.md` — mục tiêu, phạm vi, test levels, môi trường, entry/exit criteria.
- `02-test-cases.md` — toàn bộ test cases.
- `03-traceability.md` — Requirements Traceability Matrix.
- `04-dashboard.md` — dashboard tổng hợp.
- `05-bug-report.md` — Bug Report template.

## Dùng cho AI

Nếu muốn AI hiểu toàn bộ QA context, ưu tiên đưa `01-test-plan.md`, `02-test-cases.md` và `03-traceability.md`. Có thể đưa `04-dashboard.md` và `05-bug-report.md` khi AI cần xử lý trạng thái test/bug.

- `06-PROMPTS-TEST.md` — bộ prompt để AI thực thi QA/test dựa trên 5 tài liệu trên.
